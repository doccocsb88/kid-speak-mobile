# Splash Screen Image

Please save your splash screen image here as `splash_bird.png` (or another image format like .jpg).

The image should be:
- High resolution (at least 1080x1920 for phones)
- The colorful bird on rainbow cloud with "Kid Speak" text
- Optimized for mobile display
- In PNG or JPG format

Once you add the actual image file (e.g., `splash_bird.png`), you can delete this markdown file.
